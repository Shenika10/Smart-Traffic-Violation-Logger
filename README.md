# 🚦 Smart Traffic Violation Logger

A Flask-based web application for recording and managing traffic violations with QR code generation.

## ✨ Features
- Add and manage traffic violations.
- View and search violation history.
- Track fine payment status.
- Generate QR codes for violation records.

## 🛠️ Technologies Used
Python | Flask | SQLite | SQLAlchemy | HTML | CSS

## ⚙️ How to Run

```bash
pip install flask flask-sqlalchemy qrcode[pil]
python app.py
```

Open `http://127.0.0.1:5000/` in your browser.
